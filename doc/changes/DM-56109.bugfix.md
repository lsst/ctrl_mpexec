``pipetask run-qbb`` now honours ``--config-search-path``.

The search path was carried as far as the quantum-backed butler factory, and through pickling to the worker subprocesses, but was never passed to ``QuantumBackedButler.initialize``.
``pipetask pre-exec-init-qbb`` already forwarded it correctly, so storage class and datastore configuration overrides applied when writing init outputs but were silently ignored when executing quanta.
Setting ``DAF_BUTLER_CONFIG_PATH`` was previously the only way to make such overrides take effect during execution.
